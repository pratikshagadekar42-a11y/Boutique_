RAGHAVI BOUTIQUE - website concept (static, no backend)

FOLDER
  index.html        page structure
  css/style.css     all styling (colours are variables at the top)
  js/main.js        all behaviour + EDITABLE DATA at the top (IMG, CONFIG, CATEGORIES, PRODUCTS, REVIEWS)
  images/           product and banner photos

OPEN IT
  Double-click index.html (internet needed only for Google Fonts).

EDIT
  Phone, address, WhatsApp number, Instagram link : CONFIG in js/main.js
  WhatsApp opens only after CONFIG.whatsapp is set (digits with country code, e.g. 919XXXXXXXXX).
  Products (name, price, old price, photo)       : PRODUCTS in js/main.js
  Replace a photo: put the new file in images/ and update its path in IMG.

PUBLISH (free)
  Upload this whole folder to Netlify Drop, GitHub Pages or Cloudflare Pages.

NOTE
  Names, prices, discounts and reviews are demo content. Photographs are sample images and not confirmed boutique products.
  Search, bag, wishlist and the enquiry form are demos: no ordering, payment or message delivery.
